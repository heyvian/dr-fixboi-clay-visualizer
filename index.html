    How to use the clay lab

    Drop in a G-code file or explore the sample vase. Drag to orbit, scroll to zoom, or use the camera buttons to reset the view.

    Set the nozzle diameter to change bead width. Runny clay lays wider and flatter. With gravity on, it also compresses and sags more across unsupported spans.

    Switch from Fast to Accurate for finer bead and support sampling, more display pixels, and sharper studio shadows.

    Use Dimensions to label the print in 3D. Choose Fired to preview shrinkage for the selected body. Render in 3D shows its estimated color and surface finish.

    The visualizer understands common 3D printer G-code and defaults to drawing horizontal G1 moves if the file has no extrusion instructions. Check the preview against your printer and clay blend.
